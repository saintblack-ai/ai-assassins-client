# AI Assassins Client

> **Proof-of-work overview:** AI Assassins Client is the user-facing web application for an independent AI-assisted intelligence and automation platform. It combines a React/Vite interface, Supabase integration, real-time client features, Cloudflare Worker support, and deployable public experiences.

## What I Built

I developed this project as the client-side experience for a larger AI automation ecosystem. The repository demonstrates work across:

- React-based product interface development
- Vite build and preview workflows
- Supabase-connected application data
- Real-time client communication with Socket.IO
- Cloudflare Worker development and deployment support
- Public-facing dashboard/game/interactive experiences under `docs/`
- Mobile-friendly and browser-based delivery
- Iterative UI, product, and workflow development
